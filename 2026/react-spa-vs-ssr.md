# SSR is overrated: Let’s fix our SPAs instead

## Description  

Server-Side Rendering is often treated as a performance silver bullet but for many teams, it’s a source of unnecessary complexity, latency, and cost.  
In this session, we’ll challenge the SSR hype and explore how modern React SPAs, when built right, can be faster, more reliable, and easier to scale.  
Learn how to combine smart caching, prefetching, and static generation to get the best of both worlds.

## Abstract  

SSR has become the default "performance fix" but reality often tells another story. Higher latency, infrastructure complexity, and slower hydration.  
This talk reclaims the power of the SPA: we’ll explore how to build React apps that feel instant, stay SEO-friendly, and scale globally with edge caching, prefetching, and static prerendering.  
You’ll learn when SSR hurts more than it helps and how to design SPAs that truly shine in 2026.

## What the audience will gain

- A clear view of **when SSR slows down instead of speeding up**  
- Practical SPA patterns for **instant load and smooth navigation**  
- Techniques to **balance SEO, caching, and user experience**  
- Insights into **hydration, data streaming, and static prerendering**  
- Confidence to **simplify frontend architecture** without losing performance

## Target audience  

Frontend Engineers, Tech Leads, Web Architects, and Developers interested in high-performance React apps without backend complexity.

## Level

Intermediate / Advanced

## Suggested Duration  

30–45 minutes (with optional live demo)
